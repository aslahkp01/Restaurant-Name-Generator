# 🍽️ AI Restaurant Name Generator

An AI-powered web application that generates creative restaurant names and curated menu items based on any cuisine entered by the user.

Built using **Streamlit**, **LangChain**, and **Groq LLM API**.

🔗 Live Demo: https://restaurant-name-generator-5aolpawmrblprqnz3bhxqj.streamlit.app/

---

## 🚀 Features

- Generate unique restaurant names using AI
- Automatically create matching menu items
- Supports custom cuisine input
- Clean and interactive UI
- Deployed on Streamlit Cloud

---

## 🛠️ Tech Stack

- **Python 3.11**
- **Streamlit**
- **LangChain (LCEL)**
- **Groq API (Llama 3.1 Model)**
- **Git & GitHub**

---

## ⚙️ Installation (Run Locally)

1️⃣ Clone the repository

git clone https://github.com/aslahkp01/Restaurant-Name-Generator.git
cd Restaurant-Name-Generator

2️⃣ Create virtual environment

python -m venv .venv
.\.venv\Scripts\activate   # Windows

3️⃣ Install dependencies

pip install -r requirements.txt

4️⃣ Set your Groq API key

Create a .env file:

GROQ_API_KEY=your_api_key_here

5️⃣ Run the app

streamlit run app.py


🌍 Deployment

The application is deployed using Streamlit Community Cloud.

To deploy:

Push code to GitHub

Connect repository on Streamlit Cloud

Add API key in Secrets
